StartMenuFreeLayout v0.0.0 — 开始使用

一、安装与启动

压缩包只需解压一次。解压后先阅读本说明，再进入同级的 StartMenuFreeLayout 文件夹。
下面三个文件都在该程序文件夹内：
1. StartMenuFreeLayout-v0.0.0-x64.msi：首次使用先双击安装。
2. 启动开始菜单自由布局.exe：安装完成后，双击打开主控制窗口。
3. 卸载.exe：卸载软件，并清除本软件的布局、缓存、日志、自启动及私有登记。

已安装旧编号版本时，请先用旧版卸载程序卸载，再安装本版。卸载会清除旧布局，请先自行备份需要的布局文件。

二、隐藏“全部／所有程序”应用列表（可选）

这项设置用于隐藏系统开始菜单中“全部”及其下方的应用列表，保留“已固定”区域。
它不会卸载应用，也不会删除快捷方式。本软件不会自动修改这项组策略。

操作步骤：
1. 同时按下 Win + R，打开“运行”。
2. 输入 gpedit.msc，按 Enter，打开“本地组策略编辑器”。
3. 在左侧依次展开：
   用户配置 → 管理模板 → “开始”菜单和任务栏
4. 在右侧找到并双击：
   从“开始”菜单中删除“所有程序”列表
5. 选择左上方“已启用”。
6. 在左下方“请选择下列操作之一”的下拉框中，选择：
   删除并禁用设置
7. 点击“应用”，再点击“确定”。
8. 关闭并重新打开开始菜单，检查“全部”及下方列表是否已隐藏。
   如果已经隐藏，不需要重启；仍未变化时，可先保存工作，再注销并重新登录。

注意：“已启用”是启用“删除列表”这项策略，因此效果是隐藏列表。不要误选“已禁用”。
若系统找不到 gpedit.msc，当前 Windows 版本可能未提供本地组策略编辑器；可先跳过本节。

恢复显示的方法：
回到同一项策略，改为“未配置”或“已禁用”，点击“应用”和“确定”，重新打开开始菜单。
如果仍未恢复，可保存工作后注销并重新登录。修改注册表但未更改组策略，可能在策略刷新后被覆盖。

本软件的加载检查不依赖这项策略；保留“全部”列表时，完整 8×7 可用区域尚未验证，不能保证与隐藏列表后的显示效果完全一致。

微软参考说明：
https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-admx-startmenu#nomoreprogramslist

三、使用自由布局

1. 打开主控制窗口，选择“自由拖动＋点击”。
2. 打开 Windows 开始菜单，直接拖动固定图标到需要的格子，不需要按住 Ctrl。
3. 松开后图标吸附到格子，空位保持空白；单击应用可启动。
4. 将一个应用拖到另一个应用上，可创建原生文件夹；拖到已有文件夹上可加入。
5. 文件夹仅剩一个成员时会自动解散，成员继承文件夹的位置。
6. 焦点位于固定图标时，方向键按当前格子移动，跳过空位；Enter 打开应用或文件夹。
7. 按需开启“开机自启动”，登录时恢复上次使用的模式和图标位置。新安装默认关闭。

四种模式：
自由拖动＋点击：直接拖动，单击启动。
锁定位置使用：单击启动，按住 Ctrl 才能拖动。
只整理图标：直接拖动，暂停单击启动。
系统原生布局：退出自由布局，交回 Windows 管理。

还原系统布局后如果只显示两行，请点击固定区右上角“全部显示”展开。
这里的“全部显示”是展开固定图标，与上文“全部”应用列表不同。

四、文件位置与卸载

运行组件：%LOCALAPPDATA%\StartMenuFreeLayout\App\0.0.0
布局、模式、日志：%LOCALAPPDATA%\StartMenuFreeLayout\Data

安装完成后，下载的安装包和附带启动器可以移动或删除，不影响已安装程序。
请不要手动移动固定运行目录。

卸载任选一种：
进入 StartMenuFreeLayout 文件夹运行“卸载.exe”；主控制窗口点击“卸载并清除数据”；
或者在 Windows 设置 → 应用 → 已安装的应用中卸载 StartMenuFreeLayout。

卸载会清除本软件的程序、数据、缓存、日志、自启动项、私有登记及控制程序快捷方式。
Windows 已固定应用、原生文件夹、你手动修改的组策略会保留。
如需恢复“全部”应用列表，请按照第二节的“恢复显示的方法”操作。
用户另存的安装包、源码、备份不会自动删除。

五、适配范围与源码

适用于通过程序兼容性检查的 Windows 11 x64 环境，当前为实验性适配。
不支持所有 Windows 或开始菜单组件版本；Windows 更新后可能需要重新适配。
固定区列数按可用宽度计算，默认 8 列、最多 7 行；显示设置可能改变可用列数。
未提供隐藏“已固定”标题或独立调整图标大小的功能。

源码在 StartMenuFreeLayout 程序文件夹内；其中 assets 存放图标资源，tests 存放测试源码。
执行构建命令前，请先进入该程序文件夹。
构建依赖 LLVM-MinGW x64 UCRT、C++/WinRT 投影头文件、Windows SDK 头文件，
以及 Windows 自带 .NET Framework 4.x x64 C# 编译器。
示例：
.\build.ps1 -Toolchain 'C:\Dev\llvm-mingw' -WinrtHeaders 'C:\Dev\winrt-headers' -SdkHeaders 'C:\Dev\sdk-headers'

运行时不联网、不覆盖系统文件。发布包不包含个人布局或日志。
文件校验见程序文件夹内 SHA256SUMS.txt，许可见同目录 LICENSE.txt。
